f:T1955,<h2 id="github-pages-블로그-만들기-git-레포지토리-생성-및-nextjs-설치0" tabindex="-1">Github Pages 블로그 만들기: Git 레포지토리 생성 및 Next.js 설치</h2>
<p>Jekyll을 활용해 Github Pages에 블로그를 만드는 분들을 보면서, 자유도 측면에서 약간의 한계를 느꼈습니다.<br>
그래서 더 높은 유연성과 커스터마이징이 가능한 <strong>Next.js</strong>로 정적 페이지를 생성하여 블로그를 제작해보기로 했습니다.<br>
이번 기회를 통해 학습도 하고, 동시에 블로그도 만들어보고자 이 포스트를 작성하게 되었습니다.</p>
<hr>
<h2 id="1-github-repository-생성1" tabindex="-1">1. Github Repository 생성</h2>
<p>Github 블로그 개설을 위해서 <strong>Github 계정</strong>이 필요하기 때문에 계정을 생성해주시고 아래 단계를 진행해주세요.<br>
Github Pages를 통해 블로그를 만들기 위해 아래와 같이 Repository명을 설정합니다.</p>
<pre><code class="language-plain"><div class="code-block"><div class="code-title">plain</div><pre class="hljs language-plain"><code><span class="hljs-selector-attr">[username]</span><span class="hljs-selector-class">.github</span><span class="hljs-selector-class">.io</span>
</code></pre></div></code></pre>
<p>예를 들어, Github 아이디가 <code>wxexam</code>이라면 Repository 이름은 <code>wxexam.github.io</code>가 됩니다.<br>
아래 이미지를 참고해주세요.</p>
<p><img src="/post/2025-02-04-001-how-to-create-nextjs-blog-001/001-git-new-repository.png" alt="깃허브 레포지토리 생성 이미지"></p>
<p>생성이 완료되었다면 다음으로 넘어가도록 하겠습니다.</p>
<hr>
<h2 id="2-nextjs-프로젝트-생성2" tabindex="-1">2. Next.js 프로젝트 생성</h2>
<p>다음은, Next.js 프로젝트를 생성합니다.
공식 홈페이지에 최신 버전의 Next.js를 설치할 수 있는 명령어를 제공하고 있습니다.</p>
<p><img src="/post/2025-02-04-001-how-to-create-nextjs-blog-001/002-nextjs-installation-1.png" alt="Next.js 설치 명령어"></p>
<p>아래 명령어를 터미널에 입력하세요.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-string">npx</span> <span class="hljs-built_in">create-next-app@latest</span> <span class="hljs-string">my-blog</span> <span class="hljs-built_in">--typescript</span>
<span class="hljs-string">cd</span> <span class="hljs-string">my-blog</span>
</code></pre></div></code></pre>
<br>
<p>아래와 같이 프로젝트를 설정하였습니다.<br>
<img src="/post/2025-02-04-001-how-to-create-nextjs-blog-001/003-nextjs-installation-2.png" alt="Next.js 설치 과정"></p>
<ul>
<li>프로젝트 이름 : wxexam.github.io</li>
<li>TypeScript 사용안함</li>
<li>ESLint 사용</li>
<li>Tailwind CSS 사용</li>
<li>src/ 디렉토리 내부에 소스 작성</li>
<li></li>
</ul>
<h4 id="21-github-pages-배포를-위한-환경-설정3" tabindex="-1">2.1 Github Pages 배포를 위한 환경 설정</h4>
<p><code>next.config.js</code> 파일을 열어 다음과 같이 <code>output: 'export'</code> 옵션을 추가해줍니다.</p>
<pre><code class="language-javascript"><div class="code-block"><div class="code-title">javascript</div><pre class="hljs language-javascript"><code><span class="hljs-type">const</span> <span class="hljs-variable">nextConfig</span> <span class="hljs-operator">=</span> {
  output: <span class="hljs-string">&#x27;export&#x27;</span>,
};

<span class="hljs-keyword">module</span>.<span class="hljs-keyword">exports</span> = nextConfig;
</code></pre></div></code></pre>
<p><code>output: 'export'</code>는 정적 사이트로 내보내기 위해 설정합니다. github page는 정적사이트를 서비스하기 때문에 정적사이트를 생성하여 해당 파일을 github로 push해주어야 합니다.</p>
<h3 id="2-배포-브랜치-설정-및-기본-프로젝트-배포4" tabindex="-1">2. 배포 브랜치 설정 및 기본 프로젝트 배포</h3>
<p>Github Repository에 프로젝트를 Push하기 전에 로컬 Git 초기화 및 원격 저장소를 연결합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git init
git remote add origin <span class="hljs-link">https://github.com/</span>[<span class="hljs-string">username</span>]/[username].github.io.git
git add .
git commit -m &quot;Initial commit&quot;
git push -u origin main
</code></pre></div></code></pre>
<p>이제 정적 파일을 생성하고 <code>gh-pages</code> 브랜치로 배포합니다.</p>
<ol>
<li><code>package.json</code>에 배포 스크립트를 추가하세요.</li>
</ol>
<pre><code class="language-json"><div class="code-block"><div class="code-title">json</div><pre class="hljs language-json"><code><span class="hljs-comment">&quot;scripts&quot;</span>: {
  <span class="hljs-comment">&quot;dev&quot;</span>: <span class="hljs-comment">&quot;next dev&quot;</span>,
  <span class="hljs-comment">&quot;build&quot;</span>: <span class="hljs-comment">&quot;next build&quot;</span>,
  <span class="hljs-comment">&quot;deploy&quot;</span>: <span class="hljs-comment">&quot;npm run build &amp;&amp; git add out &amp;&amp; git commit -m &#x27;Deploy&#x27; &amp;&amp; git subtree push --prefix out origin gh-pages&quot;</span>
}
</code></pre></div></code></pre>
<ol start="2">
<li>배포하기:</li>
</ol>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>npm <span class="hljs-built_in">run</span> deploy
</code></pre></div></code></pre>
<h3 id="3-배포-확인5" tabindex="-1">3. 배포 확인</h3>
<p>배포가 완료된 후 Github Repository의 <code>Settings &gt; Pages</code>로 이동하면 배포된 사이트 주소를 확인할 수 있습니다.<br>
주소는 보통 다음과 같습니다.</p>
<pre><code class="language-plain"><div class="code-block"><div class="code-title">plain</div><pre class="hljs language-plain"><code><span class="hljs-link">https://</span>[<span class="hljs-string">username</span>].github.io/
</code></pre></div></code></pre>
<p>브라우저에 접속하여 정상적으로 블로그가 보이는지 확인하세요.</p>
<hr>
<p>이렇게 하면 Next.js로 Github Pages에 나만의 블로그를 성공적으로 배포할 수 있습니다!</p>
