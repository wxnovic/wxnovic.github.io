<h2 id="11-git-고급-기능1" tabindex="-1">11. Git 고급 기능</h2>
<p>Git의 기본 명령어를 충분히 익혔다면, 더 나아가 고급 기능을 활용해 작업 효율성과 협업 품질을 높일 수 있습니다. 여기서는 서브모듈, 리베이스, 스태시 등 고급 기능에 대해 자세히 설명합니다.</p>
<hr>
<h3 id="서브모듈submodule2" tabindex="-1"><strong>서브모듈(Submodule)</strong></h3>
<p>Git 서브모듈은 하나의 Git 저장소 내부에 다른 Git 저장소를 포함시키는 기능입니다. 이를 통해 프로젝트의 특정 디렉토리를 독립적인 버전 관리 대상으로 설정할 수 있습니다.</p>
<h4 id="서브모듈-추가3" tabindex="-1">서브모듈 추가</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git submodule add <span class="hljs-tag">&lt;<span class="hljs-name">서브모듈</span> <span class="hljs-attr">URL</span>&gt;</span> <span class="hljs-tag">&lt;<span class="hljs-name">디렉토리</span> <span class="hljs-attr">경로</span>&gt;</span>
</code></pre></div></code></pre>
<p>예시:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git submodule <span class="hljs-keyword">add</span><span class="language-bash"> https://github.com/example/library.git external/library</span>
</code></pre></div></code></pre>
<h4 id="서브모듈-초기화4" tabindex="-1">서브모듈 초기화</h4>
<p>저장소를 클론한 후 서브모듈을 초기화하고 업데이트합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-keyword">submodule </span>init
git <span class="hljs-keyword">submodule </span>update
</code></pre></div></code></pre>
<h4 id="서브모듈-삭제5" tabindex="-1">서브모듈 삭제</h4>
<p>서브모듈 디렉토리와 관련 설정을 삭제합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git submodule deinit -f <span class="hljs-tag">&lt;<span class="hljs-name">디렉토리</span>&gt;</span>
rm -rf <span class="hljs-tag">&lt;<span class="hljs-name">디렉토리</span>&gt;</span>
git rm <span class="hljs-tag">&lt;<span class="hljs-name">디렉토리</span>&gt;</span>
</code></pre></div></code></pre>
<hr>
<h3 id="리베이스rebase6" tabindex="-1"><strong>리베이스(Rebase)</strong></h3>
<p>리베이스는 브랜치 병합의 대안으로, 브랜치를 다른 브랜치의 최신 상태 위로 재정렬합니다. 이를 통해 깔끔한 커밋 히스토리를 유지할 수 있습니다.</p>
<h4 id="리베이스-실행7" tabindex="-1">리베이스 실행</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git rebase <span class="hljs-tag">&lt;<span class="hljs-name">브랜치명</span>&gt;</span>
</code></pre></div></code></pre>
<p>예시:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git rebase <span class="hljs-selector-tag">main</span>
</code></pre></div></code></pre>
<h4 id="리베이스-중-충돌-해결8" tabindex="-1">리베이스 중 충돌 해결</h4>
<ol>
<li>충돌 발생 시 파일 수정.</li>
<li>수정한 파일을 스테이징:<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">add</span> &lt;파일명&gt;
</code></pre></div></code></pre>
</li>
<li>리베이스 재개:<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git rebase --<span class="hljs-keyword">continue</span>
</code></pre></div></code></pre>
</li>
</ol>
<blockquote>
<p><strong>주의</strong>: 리베이스는 협업 중인 브랜치에서 사용 시 주의가 필요합니다. 커밋 히스토리가 변경될 수 있기 때문입니다.</p>
</blockquote>
<hr>
<h3 id="git-스태시stash-활용9" tabindex="-1"><strong>Git 스태시(Stash) 활용</strong></h3>
<p>Git 스태시는 작업 도중 변경 사항을 임시로 저장하고, 작업 환경을 초기화한 뒤 다시 복원할 수 있는 기능입니다.</p>
<h4 id="변경-사항-임시-저장10" tabindex="-1">변경 사항 임시 저장</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-attribute">git stash</span>
</code></pre></div></code></pre>
<h4 id="특정-이름으로-저장11" tabindex="-1">특정 이름으로 저장</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git stash <span class="hljs-built_in">push</span> -m <span class="hljs-string">&quot;작업 중인 UI 업데이트&quot;</span>
</code></pre></div></code></pre>
<h4 id="저장된-목록-보기12" tabindex="-1">저장된 목록 보기</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-attribute">git stash list</span>
</code></pre></div></code></pre>
<h4 id="변경-사항-복원13" tabindex="-1">변경 사항 복원</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git stash <span class="hljs-built_in">apply</span>
</code></pre></div></code></pre>
<h4 id="가장-최근-저장-내용-삭제14" tabindex="-1">가장 최근 저장 내용 삭제</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-attribute">git stash drop</span>
</code></pre></div></code></pre>
<h4 id="모든-스태시-삭제15" tabindex="-1">모든 스태시 삭제</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git stash clear
</code></pre></div></code></pre>
<hr>
<h2 id="12-git-사용-팁16" tabindex="-1">12. Git 사용 팁</h2>
<p>Git을 더 효율적으로 사용하기 위한 몇 가지 팁과 도구를 소개합니다.</p>
<hr>
<h3 id="gitignore-파일-작성법17" tabindex="-1"><strong>.gitignore 파일 작성법</strong></h3>
<p><code>.gitignore</code> 파일은 Git이 특정 파일이나 디렉토리를 무시하도록 설정하는 파일입니다. 예를 들어, 빌드 파일, 비밀번호가 포함된 설정 파일 등을 제외할 때 사용됩니다.</p>
<h4 id="gitignore-생성18" tabindex="-1">.gitignore 생성</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-keyword">echo</span> <span class="hljs-string">&quot;node_modules/&quot;</span> &gt;&gt; <span class="hljs-string">.gitignore</span>
<span class="hljs-keyword">echo</span> <span class="hljs-string">&quot;.env&quot;</span> &gt;&gt; <span class="hljs-string">.gitignore</span>
</code></pre></div></code></pre>
<h4 id="자주-사용되는-예제19" tabindex="-1">자주 사용되는 예제</h4>
<pre><code class="language-plaintext"><div class="code-block"><div class="code-title">plaintext</div><pre class="hljs language-plaintext"><code><span class="hljs-comment"># 환경설정 파일</span>
<span class="hljs-string">.env</span>

<span class="hljs-comment"># 빌드 폴더</span>
<span class="hljs-string">/dist</span>
<span class="hljs-string">/build</span>

<span class="hljs-comment"># 로그 파일</span>
*<span class="hljs-string">.log</span>

<span class="hljs-comment"># 운영체제 생성 파일</span>
<span class="hljs-string">.DS_Store</span>
Thumbs.db
</code></pre></div></code></pre>
<p><code>.gitignore</code>는 프로젝트 루트 디렉토리에 위치해야 합니다.</p>
<hr>
<h3 id="git-alias-설정20" tabindex="-1"><strong>Git Alias 설정</strong></h3>
<p>자주 사용하는 명령어를 짧게 줄여서 사용할 수 있도록 별칭을 설정합니다.</p>
<h4 id="alias-설정21" tabindex="-1">Alias 설정</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-keyword">config</span> --<span class="hljs-keyword">global</span> <span class="hljs-keyword">alias</span><span class="hljs-variable">.st</span> status
git <span class="hljs-keyword">config</span> --<span class="hljs-keyword">global</span> <span class="hljs-keyword">alias</span><span class="hljs-variable">.cm</span> <span class="hljs-string">&quot;commit -m&quot;</span>
git <span class="hljs-keyword">config</span> --<span class="hljs-keyword">global</span> <span class="hljs-keyword">alias</span><span class="hljs-variable">.co</span> checkout
git <span class="hljs-keyword">config</span> --<span class="hljs-keyword">global</span> <span class="hljs-keyword">alias</span><span class="hljs-variable">.br</span> branch
</code></pre></div></code></pre>
<h4 id="설정-확인22" tabindex="-1">설정 확인</h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">config</span> <span class="hljs-comment">--list</span>
</code></pre></div></code></pre>

<h3 id="git-명령어-자동-완성24" tabindex="-1"><strong>Git 명령어 자동 완성</strong></h3>
<p>터미널에서 Git 명령어를 자동 완성하도록 설정하면 생산성이 높아집니다.</p>
<h4 id="bash-사용자25" tabindex="-1">Bash 사용자</h4>

<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>curl -o ~/.git-completion.bash https://raw.githubusercontent.com/git/git/master/contrib/completion/git-completion.bash
