10:T43c8,<h3 id="마크다운markdown-언어란0" tabindex="-1">마크다운(Markdown) 언어란?</h3>
<p>**마크다운(Markdown)**은 2004년 존 그루버(John Gruber)에 의해 개발된 경량 마크업 언어입니다.
이 언어는 단순한 텍스트 기반의 문법을 사용하여 HTML로 쉽게 변환할 수 있으며, 가독성과 작성 편의성이 뛰어납니다.</p>
<h3 id="마크다운의-주요-특징1" tabindex="-1">마크다운의 주요 특징</h3>
<ul>
<li><strong>가독성이 뛰어남</strong>: 일반 텍스트로 작성되어 쉽게 읽고 이해할 수 있습니다.</li>
<li><strong>HTML 변환 가능</strong>: 별도의 편집 도구 없이도 HTML 문서로 변환할 수 있습니다.</li>
<li><strong>간단한 문법</strong>: 특수문자와 기호를 활용하여 콘텐츠를 빠르게 작성할 수 있습니다.</li>
<li><strong>다양한 플랫폼 지원</strong>: GitHub, Notion, 블로그, 위키 문서 등 여러 환경에서 활용됩니다.</li>
<li><strong>경량성</strong>: 복잡한 서식 없이도 빠르게 문서를 작성하고 공유할 수 있습니다.</li>
</ul>
<h2 id="마크다운의-필요성2" tabindex="-1">마크다운의 필요성</h2>
<p>마크다운을 사용하지 않는다면 HTML을 직접 작성해야 하는데, 이는 유지보수와 작성의 불편함을 초래할 수 있습니다.</p>
<h4 id="html로-작성했을-때3" tabindex="-1">HTML로 작성했을 때:</h4>
<pre><code class="hljs language-html"><span class="hljs-tag">&lt;<span class="hljs-name">h2</span>&gt;</span>마크다운 언어란?<span class="hljs-tag">&lt;/<span class="hljs-name">h2</span>&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">ul</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>2004년 존 그루버에 의해 개발됨<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>쉽고 직관적인 문법<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>HTML로 변환 가능<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">ul</span>&gt;</span>
</code></pre>
<h4 id="마크다운으로-작성했을-때4" tabindex="-1">마크다운으로 작성했을 때:</h4>
<pre><code class="hljs language-markdown"><span class="hljs-section">## 마크다운 언어란?</span>

<span class="hljs-bullet">-</span> 2004년 존 그루버에 의해 개발됨
<span class="hljs-bullet">-</span> 쉽고 직관적인 문법
<span class="hljs-bullet">-</span> HTML로 변환 가능
</code></pre>
<p>위와 같이 마크다운을 사용하면 더욱 간결하고 가독성이 뛰어난 문서를 작성할 수 있습니다.</p>

<p>문단을 구분하려면 한 줄을 띄우면 됩니다. 줄바꿈을 원할 경우 <code>스페이스 두 개</code>를 추가합니다.</p>
<pre><code class="hljs language-markdown">이것은 첫 번째 문단입니다.

</code></pre>

</code></pre>
<p>줄바꿈(스페이스 두 개) 예시:</p>
<pre><code class="hljs language-markdown">이것은 한 줄입니다.  
이것은 다음 줄입니다.
</code></pre>
<p><strong>HTML 변환 결과</strong>:</p>
<pre><code class="hljs language-html"><span class="hljs-tag">&lt;<span class="hljs-name">p</span>&gt;</span>
