f:T1e88,<h1 id="nextjs로-블로그-만들기-시작하기0" tabindex="-1">Next.js로 블로그 만들기: 시작하기 ✨</h1>
<p>안녕하세요, 개발자 여러분! 😊 오늘은 <strong>Next.js</strong>를 활용해서 블로그를 만드는 방법을 소개하려고 합니다. Next.js는 React 기반의 프레임워크로, SSR(서버사이드 렌더링)과 정적 사이트 생성(SSG)을 쉽게 구현할 수 있어 빠르고 최적화된 웹사이트를 만들기에 제격입니다.</p>
<hr>
<h2 id="1️⃣-프로젝트-초기-설정1" tabindex="-1">1️⃣ 프로젝트 초기 설정</h2>
<p>먼저, Next.js 프로젝트를 생성해봅시다. 아래 명령어를 터미널에서 실행하세요.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-string">npx</span> <span class="hljs-built_in">create-next-app@latest</span> <span class="hljs-string">my-nextjs-blog</span>
<span class="hljs-string">cd</span> <span class="hljs-string">my-nextjs-blog</span>
<span class="hljs-string">npm</span> <span class="hljs-string">run</span> <span class="hljs-string">dev</span>
</code></pre></div></code></pre>
<p>✅ <strong>설명</strong></p>
<ul>
<li><code>npx create-next-app@latest my-nextjs-blog</code>: 최신 Next.js 템플릿 생성.</li>
<li><code>cd my-nextjs-blog</code>: 프로젝트 폴더로 이동.</li>
<li><code>npm run dev</code>: 로컬 개발 서버 실행(<code>http://localhost:3000</code>).</li>
</ul>
<hr>
<h2 id="2️⃣-페이지-구성하기2" tabindex="-1">2️⃣ 페이지 구성하기</h2>
<p>Next.js는 파일 기반 라우팅을 사용합니다. 예를 들어, <code>pages/index.js</code>는 <code>http://localhost:3000/</code>에 매핑되고, <code>pages/about.js</code>는 <code>http://localhost:3000/about</code>에 매핑됩니다.</p>
<p><strong>예제: <code>pages/index.js</code></strong></p>
<pre><code class="language-jsx"><div class="code-block"><div class="code-title">jsx</div><pre class="hljs language-jsx"><code><span class="hljs-keyword">export</span> <span class="hljs-keyword">default</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">Home</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">return</span> (
    <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">div</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">h1</span>&gt;</span>Welcome to My Blog! 🎉<span class="hljs-tag">&lt;/<span class="hljs-name">h1</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">p</span>&gt;</span>This is a blog built with Next.js.<span class="hljs-tag">&lt;/<span class="hljs-name">p</span>&gt;</span>
    <span class="hljs-tag">&lt;/<span class="hljs-name">div</span>&gt;</span></span>
  );
}
</code></pre></div></code></pre>
<hr>
<h2 id="3️⃣-동적-라우팅-추가하기3" tabindex="-1">3️⃣ 동적 라우팅 추가하기</h2>
<p>블로그라면 포스트별로 동적 URL이 필요합니다. Next.js에서는 <code>[slug].js</code> 형식으로 파일을 생성하면 동적 라우팅을 지원합니다.</p>
<p><strong>예제: <code>pages/post/[slug].js</code></strong></p>
<pre><code class="language-jsx"><div class="code-block"><div class="code-title">jsx</div><pre class="hljs language-jsx"><code><span class="hljs-keyword">import</span> { useRouter } <span class="hljs-keyword">from</span> <span class="hljs-string">&quot;next/router&quot;</span>;

<span class="hljs-keyword">export</span> <span class="hljs-keyword">default</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">Post</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">const</span> router = <span class="hljs-title function_">useRouter</span>();
  <span class="hljs-keyword">const</span> { slug } = router.<span class="hljs-property">query</span>;

  <span class="hljs-keyword">return</span> (
    <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">div</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">h1</span>&gt;</span>Post: {slug}<span class="hljs-tag">&lt;/<span class="hljs-name">h1</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">p</span>&gt;</span>This is the content of the post &quot;{slug}&quot;.<span class="hljs-tag">&lt;/<span class="hljs-name">p</span>&gt;</span>
    <span class="hljs-tag">&lt;/<span class="hljs-name">div</span>&gt;</span></span>
  );
}
</code></pre></div></code></pre>
<p>✅ <strong>설명</strong></p>
<ul>
<li><code>useRouter</code>로 URL 매개변수(<code>slug</code>)를 가져옵니다.</li>
<li><code>http://localhost:3000/post/my-first-post</code>에 접속하면 <code>my-first-post</code>가 출력됩니다.</li>
</ul>
<hr>
<h2 id="4️⃣-정적-사이트-생성-ssg4" tabindex="-1">4️⃣ 정적 사이트 생성 (SSG)</h2>
<p>SEO 최적화를 위해 Next.js의 <code>getStaticProps</code>와 <code>getStaticPaths</code>를 활용해 정적 경로를 생성할 수 있습니다.</p>
<p><strong>예제: <code>pages/post/[slug].js</code></strong></p>
<pre><code class="language-jsx"><div class="code-block"><div class="code-title">jsx</div><pre class="hljs language-jsx"><code><span class="hljs-keyword">export</span> <span class="hljs-keyword">async</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">getStaticPaths</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">const</span> paths = [
    { <span class="hljs-attr">params</span>: { <span class="hljs-attr">slug</span>: <span class="hljs-string">&quot;my-first-post&quot;</span> } },
    { <span class="hljs-attr">params</span>: { <span class="hljs-attr">slug</span>: <span class="hljs-string">&quot;nextjs-guide&quot;</span> } },
  ];
  <span class="hljs-keyword">return</span> { paths, <span class="hljs-attr">fallback</span>: <span class="hljs-literal">false</span> };
}

<span class="hljs-keyword">export</span> <span class="hljs-keyword">async</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">getStaticProps</span>(<span class="hljs-params">{ params }</span>) {
  <span class="hljs-keyword">return</span> {
    <span class="hljs-attr">props</span>: {
      <span class="hljs-attr">slug</span>: params.<span class="hljs-property">slug</span>,
    },
  };
}

<span class="hljs-keyword">export</span> <span class="hljs-keyword">default</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">Post</span>(<span class="hljs-params">{ slug }</span>) {
  <span class="hljs-keyword">return</span> (
    <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">div</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">h1</span>&gt;</span>Post: {slug}<span class="hljs-tag">&lt;/<span class="hljs-name">h1</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">p</span>&gt;</span>This is the content of the post &quot;{slug}&quot;.<span class="hljs-tag">&lt;/<span class="hljs-name">p</span>&gt;</span>
    <span class="hljs-tag">&lt;/<span class="hljs-name">div</span>&gt;</span></span>
  );
}
</code></pre></div></code></pre>
<p>✅ <strong>설명</strong></p>
<ul>
<li><code>getStaticPaths</code>: 정적으로 생성할 경로를 지정합니다.</li>
<li><code>getStaticProps</code>: 빌드 시 데이터를 가져옵니다.</li>
</ul>
