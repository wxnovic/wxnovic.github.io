<hr>
<h2 id="1-markdown이란1" tabindex="-1">1. Markdown이란?</h2>
<p>Markdown(마크다운)은 개발자뿐만 아니라 일반 사용자도 손쉽게 사용할 수 있는 <strong>가볍고 직관적인 마크업 언어</strong>입니다.<br>
HTML처럼 복잡한 태그를 몰라도, 간단한 문법만으로 깔끔한 문서를 작성할 수 있다는 점에서 널리 사용됩니다.<br>
블로그 글, README 파일, 이메일 서식 등 <strong>거의 모든 텍스트 기반 환경에서 활용</strong>이 가능합니다.</p>
<h2 id="2-markdown의-특징2" tabindex="-1">2. Markdown의 특징</h2>
<p>Markdown이 폭넓게 사용되는 이유는 그 단순함과 유연성 덕분입니다.<br>
아래는 Markdown이 가진 대표적인 장점들입니다:</p>
<ul>
<li>
<p><strong>쉽고 간단한 문법</strong></p>
<ul>
<li>글 작성에 집중할 수 있도록 설계된 간단한 문법을 제공합니다.</li>
<li>복잡한 마크업 없이도 제목, 리스트, 코드 등을 빠르게 작성할 수 있습니다.</li>
</ul>
</li>
<li>
<p><strong>범용성</strong></p>
<ul>
<li>GitHub, Notion, 블로그 플랫폼 등 수많은 서비스에서 지원하므로, 어디서든 동일한 문법을 활용할 수 있습니다.</li>
</ul>
</li>
<li>
<p><strong>가독성과 유지보수성</strong></p>
<ul>
<li>작성된 코드는 사람이 읽기에도 이해하기 쉽고, 수정도 간편합니다.</li>
</ul>
</li>
<li>
<p><strong>HTML 변환 용이</strong></p>
<ul>
<li>작성한 Markdown 문서는 간단한 변환 과정을 통해 HTML로 변환할 수 있어 웹 개발에 유용합니다.</li>
</ul>
</li>
</ul>
<hr>
<h2 id="markdown-이렇게-활용해보세요3" tabindex="-1">Markdown, 이렇게 활용해보세요!</h2>
<p>Markdown은 단순히 글 작성 도구가 아니라, <strong>효율적인 문서 작성의 시작점</strong>입니다.<br>
간단한 서식으로도 정보를 명확하게 전달할 수 있으며, 불필요한 복잡함을 제거합니다.<br>
처음 사용해본다면, 아래 예제 문법을 연습해 보세요:</p>
<pre><code class="language-javascript"><div class="code-block"><div class="code-title">javascript</div><pre class="hljs language-javascript"><code><span class="hljs-attribute">var</span> a = <span class="hljs-number">10</span>;
<span class="hljs-comment"># 제목 작성</span>
</code></pre></div></code></pre>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-section"># 제목 작성</span>

<span class="hljs-section">## 부제목 작성</span>

<span class="hljs-bullet">-</span> 리스트 항목 1
<span class="hljs-bullet">-</span> 리스트 항목 2

<span class="hljs-strong">**굵은 텍스트**</span>
<span class="hljs-emphasis">_기울임 텍스트_</span>

[<span class="hljs-string">링크 텍스트</span>](<span class="hljs-link">https://example.com</span>)
</code></pre></div></code></pre>
<p>Markdown을 활용해 깔끔한 문서를 작성하고, 그 가치를 직접 느껴보세요!<br>
무언가를 설명하거나 공유해야 할 때, Markdown은 언제나 가장 빠르고 간단한 도구가 되어줄 겁니다.</p>
<h3 id="21-간결한-문법4" tabindex="-1">2.1 간결한 문법</h3>
<p>Markdown의 문법은 정말 간단합니다. HTML처럼 복잡한 태그를 외울 필요가 없고, 직관적인 기호들만으로 서식을 작성할 수 있죠.<br>
예를 들어, 제목을 만들고 싶다면 <code>#</code> 기호를 추가하면 끝입니다.</p>
<h4 id="예제5" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code># 큰 제목

## 중간 제목

### 작은 제목
</code></pre></div></code></pre>
<p>위 코드는 HTML로 변환되면 이렇게 됩니다:</p>
<pre><code class="language-html"><div class="code-block"><div class="code-title">html</div><pre class="hljs language-html"><code><span class="hljs-tag">&lt;<span class="hljs-name">h1</span>&gt;</span>큰 제목<span class="hljs-tag">&lt;/<span class="hljs-name">h1</span>&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">h2</span>&gt;</span>중간 제목<span class="hljs-tag">&lt;/<span class="hljs-name">h2</span>&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">h3</span>&gt;</span>작은 제목<span class="hljs-tag">&lt;/<span class="hljs-name">h3</span>&gt;</span>
</code></pre></div></code></pre>
<p>문법이 단순하다는 점은 특히 초보자들이 쉽게 배울 수 있게 하고, 전문가들에게는 작업 속도를 높이는 도구가 됩니다.</p>
<hr>
<h3 id="22-높은-가독성6" tabindex="-1">2.2 높은 가독성</h3>
<p>Markdown의 또 다른 강점은 &quot;소스 파일 자체로도 읽기 쉽다&quot;는 점입니다.<br>
HTML 코드처럼 태그들이 문서를 어지럽히지 않기 때문에 문서를 편집할 때도, 다른 사람과 협업할 때도 매우 유리하죠.</p>
<h4 id="비교-예제7" tabindex="-1">비교 예제:</h4>
<ul>
<li>Markdown:</li>
</ul>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-strong">**강조된 텍스트**</span>

<span class="hljs-bullet">- </span>첫 번째 항목
<span class="hljs-bullet">- </span>두 번째 항목
</code></pre></div></code></pre>
<ul>
<li>HTML:</li>
</ul>
<pre><code class="language-html"><div class="code-block"><div class="code-title">html</div><pre class="hljs language-html"><code><span class="hljs-tag">&lt;<span class="hljs-name">strong</span>&gt;</span>강조된 텍스트<span class="hljs-tag">&lt;/<span class="hljs-name">strong</span>&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">ul</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>첫 번째 항목<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>두 번째 항목<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">ul</span>&gt;</span>
</code></pre></div></code></pre>
<p>Markdown 파일은 이렇게 텍스트 자체로도 쉽게 이해할 수 있습니다.</p>
<hr>
<h3 id="23-다양한-플랫폼-지원8" tabindex="-1">2.3 다양한 플랫폼 지원</h3>
<p>Markdown은 다양한 도구와 플랫폼에서 기본적으로 지원되거나 플러그인을 통해 활용될 수 있습니다.<br>
특히 아래와 같은 환경에서 널리 사용됩니다:</p>
<ol>
<li><strong>GitHub</strong>: 프로젝트의 README 파일 작성에 많이 사용됩니다.</li>
<li><strong>블로그 플랫폼</strong>: Jekyll, Hexo, Hugo와 같은 정적 사이트 생성기에서 글을 작성할 때 주로 사용됩니다.</li>
<li><strong>메모 도구</strong>: Notion, Obsidian, Roam Research와 같은 생산성 도구에서도 Markdown은 기본 형식으로 사용됩니다.</li>
</ol>
<h4 id="예시9" tabindex="-1">예시:</h4>
<ul>
<li>GitHub에서 README 파일은 Markdown으로 작성하여 프로젝트 정보를 간결하고 명확하게 전달합니다.</li>
<li>블로그에서는 Markdown으로 글을 작성하면 자동으로 HTML로 변환되기 때문에 별도의 변환 작업이 필요 없습니다.</li>
</ul>
<p>Markdown은 이렇게 어디에서든지 사용할 수 있는 범용성 덕분에 개발자들뿐 아니라 일반 사용자들에게도 매력적인 도구로 자리 잡았습니다.</p>
<h2 id="3-기본-문법10" tabindex="-1">3. 기본 문법</h2>
<p>마크다운 언어의 기본 문법은 다음과 같습니다.</p>
<h3 id="31-제목headers11" tabindex="-1">3.1 제목(Headers)</h3>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code># <span class="hljs-comment">// h1</span>

## <span class="hljs-comment">// h2</span>

### <span class="hljs-comment">// h3</span>

#### <span class="hljs-comment">// h4</span>

##### <span class="hljs-comment">// h5</span>

###### <span class="hljs-comment">// h6</span>
</code></pre></div></code></pre>
<h1>h1</h1>
<h2>h2</h2>
<h3>h3</h3>
<h4>h4</h4>
<h5>h5</h5>
<h6>h6</h6>
<hr>
<h3 id="32-텍스트-서식12" tabindex="-1">3.2 텍스트 서식</h3>
<p>Markdown은 텍스트 서식을 간단한 기호로 표현할 수 있도록 설계되었습니다. 아래는 Markdown에서 사용할 수 있는 주요 텍스트 서식의 종류와 사용법입니다.</p>
<hr>
<h3 id="1-굵은-텍스트-bold13" tabindex="-1">1. <strong>굵은 텍스트 (Bold)</strong></h3>
<p>텍스트를 강조하고 싶을 때 굵은 텍스트를 사용할 수 있습니다.<br>
<code>**텍스트**</code> 또는 <code>__텍스트__</code>를 사용하면 됩니다.</p>
<h4 id="예제14" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-strong">**굵은 텍스트**</span>  
<span class="hljs-strong">**굵은 텍스트**</span>
</code></pre></div></code></pre>
<h4 id="출력15" tabindex="-1">출력:</h4>
<p><strong>굵은 텍스트</strong><br>
<strong>굵은 텍스트</strong></p>
<hr>
<h3 id="2-기울임-텍스트-italic16" tabindex="-1">2. <em>기울임 텍스트 (Italic)</em></h3>
<p>기울임 텍스트는 중요하지만 덜 강조하고 싶은 경우 사용합니다.<br>
<code>*텍스트*</code> 또는 <code>_텍스트_</code>로 작성합니다.</p>
<h4 id="예제17" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-literal">_</span>기울임 텍스트<span class="hljs-literal">_</span>  
<span class="hljs-literal">_</span>기울임 텍스트<span class="hljs-literal">_</span>
</code></pre></div></code></pre>
<h4 id="출력18" tabindex="-1">출력:</h4>
<p><em>기울임 텍스트</em><br>
<em>기울임 텍스트</em></p>
<hr>
<h3 id="3-취소선-텍스트-strikethrough19" tabindex="-1">3. <s>취소선 텍스트 (Strikethrough)</s></h3>
<p>텍스트에 취소선을 넣고 싶을 때는 <code>~~텍스트~~</code>를 사용합니다.</p>
<h4 id="예제20" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code>~~취소선 텍스트~~
</code></pre></div></code></pre>
<h4 id="출력21" tabindex="-1">출력:</h4>
<p><s>취소선 텍스트</s></p>
<hr>
<h3 id="4-인라인-코드-inline-code22" tabindex="-1">4. <code>인라인 코드 (Inline Code)</code></h3>
<p>코드 조각을 강조할 때는 텍스트를 백틱(`)으로 감싸서 사용합니다.</p>
<h4 id="예제23" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code>`print(<span class="hljs-string">&quot;Hello, Markdown!&quot;</span>)`
</code></pre></div></code></pre>
<h4 id="출력24" tabindex="-1">출력:</h4>
<p><code>print(&quot;Hello, Markdown!&quot;)</code></p>
<hr>
<h3 id="5-인용문-blockquote25" tabindex="-1">5. 인용문 (Blockquote)</h3>
<p>인용문은 <code>&gt;</code> 기호를 사용하여 작성합니다. 여러 줄을 인용하거나, 중첩 인용도 가능합니다.</p>
<h4 id="예제26" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-meta prompt_">&gt;</span> <span class="language-javascript">이것은 인용문입니다.</span>
<span class="hljs-meta prompt_">&gt;</span>
<span class="hljs-meta prompt_">&gt;</span> <span class="language-javascript">&gt; 중첩된 인용문입니다.</span>
</code></pre></div></code></pre>
<h4 id="출력27" tabindex="-1">출력:</h4>
<blockquote>
<p>이것은 인용문입니다.</p>
<blockquote>
<p>중첩된 인용문입니다.</p>
</blockquote>
</blockquote>
<hr>
<h3 id="6-리스트-lists28" tabindex="-1">6. 리스트 (Lists)</h3>
<h4 id="순서-없는-리스트-unordered-list29" tabindex="-1">순서 없는 리스트 (Unordered List)</h4>
<p><code>-</code>, <code>*</code>, 또는 <code>+</code>를 사용하여 순서 없는 리스트를 작성할 수 있습니다.</p>
<h4 id="예제30" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-bullet">-</span> 항목 1
<span class="hljs-bullet">-</span> 항목 2
<span class="hljs-bullet">  -</span> 하위 항목
</code></pre></div></code></pre>
<h4 id="출력31" tabindex="-1">출력:</h4>
<ul>
<li>항목 1</li>
<li>항목 2
<ul>
<li>하위 항목</li>
</ul>
</li>
</ul>
<h4 id="순서-있는-리스트-ordered-list32" tabindex="-1">순서 있는 리스트 (Ordered List)</h4>
<p>숫자와 점(<code>1.</code>)을 사용하여 순서 있는 리스트를 작성합니다.</p>
<h4 id="예제33" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-bullet">1.</span> 첫 번째
<span class="hljs-bullet">2.</span> 두 번째
<span class="hljs-bullet">   1.</span> 하위 항목
</code></pre></div></code></pre>
<h4 id="출력34" tabindex="-1">출력:</h4>
<ol>
<li>첫 번째</li>
<li>두 번째
<ol>
<li>하위 항목</li>
</ol>
</li>
</ol>
<hr>
<h3 id="7-하이라이트-highlight35" tabindex="-1">7. 하이라이트 (Highlight)</h3>
<p>기본 Markdown에서는 하이라이트 기능이 없지만, 일부 플랫폼에서는 <code>==텍스트==</code>를 사용하여 하이라이트를 추가할 수 있습니다.<br>
예를 들어, GitHub Issues에서는 이 기능이 지원되지 않지만, 다른 확장된 Markdown 도구에서 동작합니다.</p>
<h4 id="예제36" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-operator">=</span><span class="hljs-operator">=</span>강조된 텍스트<span class="hljs-operator">=</span><span class="hljs-operator">=</span>
</code></pre></div></code></pre>
<h4 id="출력37" tabindex="-1">출력:</h4>
<p>==(하이라이트가 지원되는 플랫폼에서만 적용됨)==</p>
<p>Markdown은 단순하지만 이런 다양한 텍스트 서식으로 콘텐츠를 아름답게 꾸밀 수 있습니다. 필요한 서식을 선택해서 문서를 더욱 매력적으로 만들어 보세요!</p>
<hr>
<h3 id="33-이미지-삽입38" tabindex="-1">3.3 이미지 삽입</h3>
<p>Markdown에서 이미지를 삽입하려면 <code>![대체 텍스트](이미지 URL)</code> 형식을 사용합니다. 대체 텍스트는 이미지가 로드되지 않을 경우 표시될 텍스트이며, 이미지를 설명하는 용도로도 사용됩니다.</p>
<h4 id="기본-문법39" tabindex="-1">기본 문법:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code>!<span class="hljs-selector-attr">[대체 텍스트]</span>(이미지 URL)
</code></pre></div></code></pre>
<h4 id="예제40" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code>!<span class="hljs-selector-attr">[마크다운 가이드]</span>(<span class="hljs-attribute">https</span>:<span class="hljs-comment">//example.com/image.png)</span>
</code></pre></div></code></pre>
<h4 id="출력41" tabindex="-1">출력:</h4>
<p><img src="https://example.com/image.png" alt="마크다운 가이드"></p>
<h4 id="이미지-크기-조정42" tabindex="-1">이미지 크기 조정</h4>
<p>Markdown 자체로는 이미지 크기를 조정할 수 없지만, HTML 태그를 함께 사용하여 크기를 조절할 수 있습니다.</p>
<h4 id="html을-활용한-예제43" tabindex="-1">HTML을 활용한 예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code>&lt;img <span class="hljs-attribute">src</span>=<span class="hljs-string">&quot;https://example.com/image.png&quot;</span> <span class="hljs-attribute">alt</span>=<span class="hljs-string">&quot;마크다운 가이드&quot;</span> <span class="hljs-attribute">width</span>=<span class="hljs-string">&quot;300&quot;</span>&gt;
</code></pre></div></code></pre>
<h4 id="출력44" tabindex="-1">출력:</h4>
<img src="/post/2025-01-26-001-markdown-guide/test.webp" alt="마크다운 가이드" width="300">
<h4 id="이미지-링크로-활용45" tabindex="-1">이미지 링크로 활용</h4>
<p>이미지를 클릭했을 때 다른 페이지로 이동하게 하려면 <code>[![이미지 설명](이미지 URL)](링크 URL)</code> 형식을 사용합니다.</p>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code>[<span class="hljs-name">!</span>[<span class="hljs-name">마크다운</span> 가이드](<span class="hljs-name">https://example.com/image.png</span>)](<span class="hljs-name">https://example.com</span>)
</code></pre></div></code></pre>
<h4 id="출력46" tabindex="-1">출력:</h4>
<p><a href="https://example.com"><img src="/post/2025-01-26-001-markdown-guide/test.webp" alt="마크다운 가이드"></a></p>
<h2 id="4-고급-문법47" tabindex="-1">4. 고급 문법</h2>
<p>Markdown은 기본적인 텍스트 서식 외에도 문서를 더욱 구조화하거나 시각적으로 풍부하게 만드는 고급 문법을 제공합니다. 이제 Markdown의 고급 문법을 하나씩 살펴보겠습니다.</p>
<hr>
<h3 id="41-표-table48" tabindex="-1">4.1 표 (Table)</h3>
<p>Markdown을 사용하면 간단한 기호만으로 표를 만들 수 있습니다.<br>
표는 <code>|</code>(세로선)과 <code>-</code>(하이픈)을 조합하여 작성합니다.</p>
<h4 id="기본-작성법49" tabindex="-1">기본 작성법:</h4>
<ul>
<li><code>|</code>는 열(Column)을 구분합니다.</li>
<li><code>-</code>는 헤더와 본문을 구분하는 역할을 합니다.</li>
<li><code>:</code>를 사용하여 텍스트 정렬을 설정할 수 있습니다.</li>
</ul>
<h4 id="예제50" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code>|<span class="hljs-string"> 헤더1     </span>|<span class="hljs-string">    헤더2    </span>|<span class="hljs-string">       헤더3 </span>|
|<span class="hljs-string"> :-------- </span>|<span class="hljs-string"> :---------: </span>|<span class="hljs-string"> ----------: </span>|
|<span class="hljs-string"> 왼쪽 정렬 </span>|<span class="hljs-string"> 가운데 정렬 </span>|<span class="hljs-string"> 오른쪽 정렬 </span>|
|<span class="hljs-string"> 데이터1   </span>|<span class="hljs-string">   데이터2   </span>|<span class="hljs-string">     데이터3 </span>|
|<span class="hljs-string"> 데이터4   </span>|<span class="hljs-string">   데이터5   </span>|<span class="hljs-string">     데이터6 </span>|
</code></pre></div></code></pre>
<h4 id="출력51" tabindex="-1">출력:</h4>
<table>
<thead>
<tr>
<th style="text-align:left">헤더1</th>
<th style="text-align:center">헤더2</th>
<th style="text-align:right">헤더3</th>
</tr>
</thead>
<tbody>
<tr>
<td style="text-align:left">왼쪽 정렬</td>
<td style="text-align:center">가운데 정렬</td>
<td style="text-align:right">오른쪽 정렬</td>
</tr>
<tr>
<td style="text-align:left">데이터1</td>
<td style="text-align:center">데이터2</td>
<td style="text-align:right">데이터3</td>
</tr>
<tr>
<td style="text-align:left">데이터4</td>
<td style="text-align:center">데이터5</td>
<td style="text-align:right">데이터6</td>
</tr>
</tbody>
</table>
<hr>
<h3 id="42-인용문-blockquote52" tabindex="-1">4.2 인용문 (Blockquote)</h3>
<p>인용문은 텍스트 앞에 <code>&gt;</code> 기호를 추가하여 작성합니다.<br>
중첩된 인용문은 <code>&gt;&gt;</code>와 같은 방식으로 표현할 수 있습니다. 인용문은 문서를 읽는 사람에게 중요한 메시지나 참고 내용을 강조할 때 유용합니다.</p>
<h4 id="예제53" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-meta prompt_">&gt;</span> <span class="language-javascript">이것은 기본 인용문입니다.</span>
<span class="hljs-meta prompt_">&gt;</span>
<span class="hljs-meta prompt_">&gt;</span> <span class="language-javascript">&gt; 이것은 중첩된 인용문입니다.</span>
<span class="hljs-meta prompt_">&gt;</span> <span class="language-javascript">&gt;</span>
<span class="hljs-meta prompt_">&gt;</span> <span class="language-javascript">&gt; &gt; 더 깊은 중첩된 인용문입니다.</span>
</code></pre></div></code></pre>
<h4 id="출력54" tabindex="-1">출력:</h4>
<blockquote>
<p>이것은 기본 인용문입니다.</p>
<blockquote>
<p>이것은 중첩된 인용문입니다.</p>
<blockquote>
<p>더 깊은 중첩된 인용문입니다.</p>
</blockquote>
</blockquote>
</blockquote>
<h4 id="응용55" tabindex="-1">응용:</h4>
<p>인용문 안에 다른 Markdown 요소(링크, 굵은 텍스트 등)를 포함할 수도 있습니다.</p>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-quote">&gt; <span class="hljs-strong">**참고:**</span> 더 많은 정보를 원한다면 [<span class="hljs-string">Markdown 문서</span>](<span class="hljs-link">https://example.com</span>)를 참고하세요.</span>
</code></pre></div></code></pre>
<h4 id="출력56" tabindex="-1">출력:</h4>
<blockquote>
<p><strong>참고:</strong> 더 많은 정보를 원한다면 <a href="https://example.com">Markdown 문서</a>를 참고하세요.</p>
</blockquote>
<hr>
<h3 id="43-체크리스트-checkbox57" tabindex="-1">4.3 체크리스트 (Checkbox)</h3>
<p>Markdown은 작업 목록이나 TODO 리스트를 작성할 수 있는 체크리스트 문법을 제공합니다.<br>
<code>- [ ]</code>로 체크박스를 만들고, <code>- [x]</code>로 체크된 상태를 나타낼 수 있습니다.</p>
<h4 id="예제58" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-bullet">- </span>[x] 완료된 작업
<span class="hljs-bullet">- </span>[ ] 진행 중인 작업
<span class="hljs-bullet">- </span>[ ] 새로운 작업 추가
</code></pre></div></code></pre>
<h4 id="출력59" tabindex="-1">출력:</h4>
<ul>
<li>[x] 완료된 작업</li>
<li>[ ] 진행 중인 작업</li>
<li>[ ] 새로운 작업 추가</li>
</ul>
<p>체크리스트는 GitHub와 같은 협업 도구에서 유용하게 활용됩니다. 예를 들어, 프로젝트의 TODO 리스트를 작성하거나 이슈에 필요한 작업 항목을 기록할 때 사용할 수 있습니다.</p>
<hr>
<p>Markdown의 고급 문법은 문서를 더욱 풍부하고 기능적으로 만들어줍니다.<br>
이러한 요소를 적절히 활용하여 시각적으로 깔끔하고 이해하기 쉬운 문서를 작성해 보세요!</p>
<hr>
<h2 id="5-markdown과-html60" tabindex="-1">5. Markdown과 HTML</h2>
<p>Markdown은 단순한 문법으로 문서를 작성할 수 있는 장점이 있지만, 경우에 따라 HTML 태그를 직접 사용하는 것이 필요할 때도 있습니다. Markdown과 HTML은 호환되기 때문에 두 가지를 함께 사용할 수 있습니다. 아래에서 Markdown과 HTML의 호환성과 사용 방법에 대해 살펴보겠습니다.</p>
<hr>
<h3 id="51-html-태그와의-호환성61" tabindex="-1">5.1 HTML 태그와의 호환성</h3>
<p>Markdown 문서 안에서 HTML 태그를 사용할 수 있습니다.<br>
이는 Markdown의 한계(특히 고급 레이아웃이나 스타일링)에서 벗어나야 할 때 매우 유용합니다.<br>
예를 들어, 표준 Markdown 문법으로는 불가능한 CSS 스타일 적용, 특수 레이아웃 구성 등을 HTML 태그로 보완할 수 있습니다.</p>
<h4 id="예제-markdown과-html-혼합-사용62" tabindex="-1">예제: Markdown과 HTML 혼합 사용</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code># Markdown과 HTML 함께 사용하기

<span class="hljs-tag">&lt;<span class="hljs-name">p</span> <span class="hljs-attr">style</span>=<span class="hljs-string">&quot;color:blue; font-weight:bold;&quot;</span>&gt;</span>이 문장은 HTML로 작성되었습니다.<span class="hljs-tag">&lt;/<span class="hljs-name">p</span>&gt;</span>

**이 문장은 Markdown으로 작성되었습니다.**

<span class="hljs-tag">&lt;<span class="hljs-name">ul</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>HTML 리스트 항목 1<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>HTML 리스트 항목 2<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">ul</span>&gt;</span>
</code></pre></div></code></pre>
<h4 id="출력63" tabindex="-1">출력:</h4>
<h1 id="markdown과-html-함께-사용하기64" tabindex="-1">Markdown과 HTML 함께 사용하기</h1>
<p style="color:blue; font-weight:bold;">이 문장은 HTML로 작성되었습니다.</p>
<p><strong>이 문장은 Markdown으로 작성되었습니다.</strong></p>
<ul>
  <li>HTML 리스트 항목 1</li>
  <li>HTML 리스트 항목 2</li>
</ul>
<hr>
<h3 id="52-markdown에서-html-사용하기65" tabindex="-1">5.2 Markdown에서 HTML 사용하기</h3>
<p>Markdown에서는 기본 문법으로는 불가능한 기능들을 구현하기 위해 HTML 태그를 활용할 수 있습니다.<br>
예를 들어, 특정 스타일링이 필요한 경우 HTML 태그를 섞어서 사용할 수 있습니다.</p>
<h4 id="html로-스타일링-추가66" tabindex="-1">HTML로 스타일링 추가</h4>
<p>아래는 HTML 태그를 사용해 텍스트 색상을 변경하거나 텍스트 크기를 조절하는 예제입니다.</p>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code># Markdown과 HTML 조합하기

Markdown 문서에서 <span class="hljs-tag">&lt;<span class="hljs-name">span</span> <span class="hljs-attr">style</span>=<span class="hljs-string">&quot;color:red;&quot;</span>&gt;</span>이런 식으로<span class="hljs-tag">&lt;/<span class="hljs-name">span</span>&gt;</span> 색상을 지정할 수 있습니다.

<span class="hljs-tag">&lt;<span class="hljs-name">div</span> <span class="hljs-attr">style</span>=<span class="hljs-string">&quot;background-color:#ff0000; padding:10px;&quot;</span>&gt;</span>
HTML로 작성된 박스입니다.

<div style="background-color:#ff0000; padding:10px;">
HTML로 작성된 박스입니다.
</div>

<h4 id="html로-특수-구조-작성69" tabindex="-1">HTML로 특수 구조 작성</h4>
<p>Markdown으로는 다루기 어려운 특수 레이아웃도 HTML로 작성할 수 있습니다.</p>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-tag">&lt;<span class="hljs-name">table</span>&gt;</span>

<hr>
<p>Markdown과 HTML을 함께 사용하면 기본 Markdown 문법의 단순성을 유지하면서도 복잡하고 세부적인 작업을 처리할 수 있습니다.<br>
HTML 태그를 적절히 활용하여 필요한 기능을 추가하거나 스타일을 커스터마이징해 보세요.</p>
<hr>
<h2 id="6-markdown-사용-사례71" tabindex="-1">6. Markdown 사용 사례</h2>
<p>Markdown은 간단한 문법과 뛰어난 호환성 덕분에 다양한 환경에서 활용되고 있습니다.<br>
아래에서는 Markdown이 사용되는 대표적인 사례들을 살펴보겠습니다.</p>
<hr>
<h3 id="61-github에서-사용72" tabindex="-1">6.1 GitHub에서 사용</h3>
<p>Markdown은 GitHub에서 프로젝트 문서화와 협업에 필수적인 도구로 사용됩니다.<br>
특히 프로젝트 설명과 작업 관리에 큰 도움이 됩니다.</p>
<h4 id="1-readme-파일-작성73" tabindex="-1">1. <strong>README 파일 작성</strong></h4>
<p>프로젝트를 소개하고 설치 및 사용법을 제공하는 README.md 파일은 Markdown으로 작성됩니다.</p>
<h4 id="예제74" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-comment"># 프로젝트 이름</span>

이 프로젝트는 Markdown 예제를 제공합니다.

<span class="hljs-comment">## 설치 방법</span>

```bash
git <span class="hljs-built_in">clone</span> https://github.com/example/project.git <span class="hljs-built_in">cd</span> project npm install
```
</code></pre></div></code></pre>
<h4 id="2-이슈-및-pr-템플릿75" tabindex="-1">2. <strong>이슈 및 PR 템플릿</strong></h4>
<p>GitHub의 이슈(버그 리포트, 기능 요청)나 Pull Request에 작업 리스트를 포함해 협업을 효율적으로 진행할 수 있습니다.</p>
<h4 id="예제76" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-section">## 작업 항목</span>

<span class="hljs-bullet">-</span> [x] 기능 구현 완료
<span class="hljs-bullet">-</span> [ ] 코드 리뷰 대기
<span class="hljs-bullet">-</span> [ ] 배포 준비
</code></pre></div></code></pre>
<p>GitHub에서 Markdown을 사용하면 단순한 텍스트 파일로 협업 문서를 작성하고 공유할 수 있습니다.</p>
<hr>
<h3 id="62-블로그-플랫폼에서-사용77" tabindex="-1">6.2 블로그 플랫폼에서 사용</h3>
<p>Markdown은 블로그 글 작성 시 간편함과 유연성을 제공합니다.<br>
Jekyll, Hexo, Hugo와 같은 정적 사이트 생성기에서는 Markdown 파일 하나만으로 HTML 기반의 완성된 블로그 글을 생성할 수 있습니다.<br>
지금 보고 계신 이 사이트도 Markdown으로 작성된 파일을 불러와서 HTML로 렌더링하여 출력해주고 있습니다.</p>
<h4 id="예제78" tabindex="-1">예제:</h4>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-section"># 블로그 제목</span>

Markdown은 간단한 문법으로 글을 작성할 수 있도록 도와줍니다.

<span class="hljs-section">## 주요 특징</span>

<span class="hljs-bullet">-</span> 직관적인 문법
<span class="hljs-bullet">-</span> 다양한 서식 지원
<span class="hljs-bullet">-</span> 플랫폼 간 호환성
</code></pre></div></code></pre>
<p>정적 사이트 생성기를 통해 HTML 변환이 자동으로 이루어지므로 별도의 변환 작업이 필요 없습니다.</p>
<hr>
<h3 id="63-메모-도구에서-사용79" tabindex="-1">6.3 메모 도구에서 사용</h3>
<p>Markdown은 메모 도구에서도 널리 사용됩니다.<br>
Notion, Obsidian, Roam Research 같은 생산성 도구는 Markdown을 기반으로 작동하며, 메모 작성과 문서 관리에 유용합니다.</p>
<h4 id="주요-활용-사례80" tabindex="-1">주요 활용 사례:</h4>
<ol>
<li>
<p><strong>빠른 노트 작성</strong>:<br>
간단한 문법으로 내용을 빠르게 기록할 수 있습니다.</p>
<p>예제:</p>
<pre><code class="language-markdown"><div class="code-block"><div class="code-title">markdown</div><pre class="hljs language-markdown"><code><span class="hljs-section">## 오늘의 할 일</span>

<span class="hljs-bullet">-</span> [x] 회의 준비
<span class="hljs-bullet">-</span> [ ] 코드 리뷰
<span class="hljs-bullet">-</span> [ ] 블로그 글 작성
</code></pre></div></code></pre>
</li>
<li>
<p><strong>문서 연결</strong>:<br>
Obsidian과 같은 도구에서는 문서 간 연결을 위해 <code>[[문서 제목]]</code> 문법을 사용합니다.</p>
</li>
</ol>
<h4 id="장점81" tabindex="-1">장점:</h4>
<ul>
<li>메모 간 연결과 정리가 쉬움</li>
<li>텍스트 파일로 저장되어 데이터 이동성과 보존성이 높음</li>
</ul>
<hr>
<p>Markdown은 다양한 플랫폼에서 문서를 간단히 작성하고 공유할 수 있는 강력한 도구입니다.<br>
GitHub에서의 협업, 블로그 작성, 그리고 개인 메모 도구까지 Markdown은 어디에서든 활용 가능한 최고의 선택입니다.</p>
<hr>
<h2 id="마무리82" tabindex="-1">마무리</h2>
<p>Markdown은 간단한 문법과 뛰어난 유연성 덕분에 개발자뿐만 아니라 일반 사용자들에게도 사랑받는 도구입니다.<br>
복잡한 HTML 태그를 외울 필요 없이 직관적인 기호로 텍스트 서식을 지정할 수 있고, 다양한 플랫폼과의 호환성을 통해 문서 작성의 효율성을 극대화할 수 있습니다.</p>
<p>Markdown은 다음과 같은 장점을 제공합니다:</p>
<ul>
<li><strong>간단하고 직관적인 문법</strong>: 초보자도 빠르게 배울 수 있습니다.</li>
<li><strong>높은 생산성</strong>: 빠르게 문서를 작성하고 쉽게 수정할 수 있습니다.</li>
<li><strong>광범위한 활용</strong>: GitHub, 블로그, 메모 도구 등에서 다양하게 활용 가능합니다.</li>
</ul>
<p>Markdown은 단순한 텍스트 기반 문서 도구를 넘어, 정보를 명확하고 효율적으로 전달할 수 있는 강력한 도구입니다.<br>
이제 여러분도 Markdown을 활용해 문서를 작성하고 관리하며, 효율성을 높여보세요!</p>
<p>마지막으로, Markdown의 핵심은 단순함과 가독성입니다.<br>
Markdown을 통해 복잡한 문서를 간단하게 작성하고, 정보 전달의 질을 높이는 데 도전해 보세요!</p>
