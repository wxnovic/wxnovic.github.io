<h2 id="13-문제-해결1" tabindex="-1">13. 문제 해결</h2>
<p>Git을 사용하다 보면 다양한 문제가 발생할 수 있습니다. 충돌, 원격 저장소 오류, 잘못된 커밋 등 자주 발생하는 문제와 그 해결 방법을 정리했습니다.</p>
<hr>
<h3 id="1-커밋-충돌2" tabindex="-1"><strong>1. 커밋 충돌</strong></h3>
<h4 id="문제-상황3" tabindex="-1">문제 상황</h4>
<p>두 브랜치의 동일한 파일에서 서로 다른 내용이 변경되었을 경우 충돌이 발생합니다.</p>
<h4 id="해결-방법4" tabindex="-1">해결 방법</h4>
<ol>
<li>
<p><strong>충돌 내용 확인</strong></p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-attribute">git status</span>
</code></pre></div></code></pre>
<p>충돌이 발생한 파일은 <code>Unmerged paths</code> 아래 표시됩니다.</p>
</li>
<li>
<p><strong>파일 수정</strong>
충돌 부분은 아래 형식으로 표시됩니다. 두 내용 중 선택하거나 새로운 내용을 작성합니다.</p>
<pre><code class="language-plaintext"><div class="code-block"><div class="code-title">plaintext</div><pre class="hljs language-plaintext"><code>&lt;&lt;&lt;&lt;&lt;&lt;&lt; HEAD
<span class="hljs-section">브랜치 A의 내용
=======</span>
브랜치 B의 내용
&gt;&gt;&gt;&gt;&gt;&gt;&gt; 브랜치명
</code></pre></div></code></pre>
</li>
<li>
<p><strong>수정 완료 후 변경 사항 스테이징</strong></p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">add</span> &lt;파일명&gt;
</code></pre></div></code></pre>
</li>
<li>
<p><strong>병합 완료</strong></p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code><span class="hljs-attribute">git commit</span>
</code></pre></div></code></pre>
</li>
</ol>
<hr>
<h3 id="2-원격-저장소와의-충돌5" tabindex="-1"><strong>2. 원격 저장소와의 충돌</strong></h3>
<h4 id="문제-상황6" tabindex="-1">문제 상황</h4>
<p>원격 저장소에 있는 내용이 로컬 저장소와 다를 때 <code>git push</code> 시 오류가 발생합니다.</p>
<pre><code class="language-plaintext"><div class="code-block"><div class="code-title">plaintext</div><pre class="hljs language-plaintext"><code><span class="hljs-keyword">error: </span>failed to push some refs to &lt;원격 저장소 URL&gt;
</code></pre></div></code></pre>
<h4 id="해결-방법7" tabindex="-1">해결 방법</h4>
<ol>
<li>
<p><strong>원격 저장소의 변경 사항을 병합</strong></p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git pull origin <span class="hljs-tag">&lt;<span class="hljs-name">브랜치명</span>&gt;</span>
</code></pre></div></code></pre>
</li>
<li>
<p><strong>변경 사항을 다시 푸시</strong></p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">push</span> <span class="hljs-built_in">origin</span> &lt;브랜치명&gt;
</code></pre></div></code></pre>
</li>
</ol>
<hr>
<h3 id="3-삭제된-파일-복구8" tabindex="-1"><strong>3. 삭제된 파일 복구</strong></h3>
<h4 id="문제-상황9" tabindex="-1">문제 상황</h4>
<p>로컬에서 삭제된 파일을 복구하려면 아래 명령어를 사용합니다.</p>
<h4 id="해결-방법10" tabindex="-1">해결 방법</h4>
<ol>
<li>
<p>특정 파일 복구:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git checkout HEAD <span class="hljs-comment">-- &lt;파일명&gt;</span>
</code></pre></div></code></pre>
</li>
<li>
<p>모든 삭제된 파일 복구:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">restore</span> .
</code></pre></div></code></pre>
</li>
</ol>
<hr>
<h3 id="4-잘못된-커밋-수정11" tabindex="-1"><strong>4. 잘못된 커밋 수정</strong></h3>
<h4 id="문제-상황12" tabindex="-1">문제 상황</h4>
<p>커밋 메시지나 변경 내용을 잘못 기록했을 경우.</p>
<h4 id="해결-방법13" tabindex="-1">해결 방법</h4>
<ol>
<li>
<p>마지막 커밋 수정:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-keyword">commit</span> <span class="hljs-comment">--amend</span>
</code></pre></div></code></pre>
</li>
<li>
<p>여러 커밋 수정 (인터랙티브 리베이스):</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git rebase -i HEAD~<span class="hljs-tag">&lt;<span class="hljs-name">수정할</span> <span class="hljs-attr">커밋</span> <span class="hljs-attr">수</span>&gt;</span>
</code></pre></div></code></pre>
</li>
</ol>
<hr>
<h3 id="5-실수로-삭제된-브랜치-복구14" tabindex="-1"><strong>5. 실수로 삭제된 브랜치 복구</strong></h3>
<h4 id="문제-상황15" tabindex="-1">문제 상황</h4>
<p>로컬에서 브랜치를 삭제한 경우 복구하려면 아래 명령어를 사용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">ref</span>log
</code></pre></div></code></pre>
<p>이후 브랜치가 가리키던 커밋 ID를 확인하고 복원합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git checkout -b <span class="hljs-tag">&lt;<span class="hljs-name">브랜치명</span>&gt;</span> <span class="hljs-tag">&lt;<span class="hljs-name">커밋</span> <span class="hljs-attr">ID</span>&gt;</span>
</code></pre></div></code></pre>
<hr>
<h3 id="6-git-크리덴셜-문제16" tabindex="-1"><strong>6. Git 크리덴셜 문제</strong></h3>
<h4 id="문제-상황17" tabindex="-1">문제 상황</h4>
<p>원격 저장소 인증 오류가 발생하거나 비밀번호를 자주 요청받는 경우.</p>
<h4 id="해결-방법18" tabindex="-1">해결 방법</h4>
<ol>
<li>
<p>Git 크리덴셜 캐시 활성화:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">config</span> <span class="hljs-comment">--global credential.helper cache</span>
</code></pre></div></code></pre>
</li>
<li>
<p>Windows에서는 크리덴셜 관리자를 사용:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-title">bash</div><pre class="hljs language-bash"><code>git <span class="hljs-built_in">config</span> <span class="hljs-comment">--global credential.helper manager</span>
</code></pre></div></code></pre>
</li>
</ol>
<hr>
<h2 id="14-결론19" tabindex="-1">14. 결론</h2>
<p>Git은 프로젝트의 모든 변경 사항을 기록하고 팀 협업을 가능하게 하는 강력한 도구입니다. 효율적으로 사용하기 위해서는 기본 사용법뿐만 아니라 문제 해결 능력도 필수적입니다. 다음은 Git을 효과적으로 활용하기 위한 최종 요약입니다.</p>
<hr>
<h3 id="1-git-학습의-중요성20" tabindex="-1"><strong>1. Git 학습의 중요성</strong></h3>
<ul>
<li>Git은 소프트웨어 개발뿐만 아니라 데이터 관리, 문서 작성 등 다양한 분야에서 사용됩니다.</li>
<li>실수를 줄이고 생산성을 높이기 위해 꾸준히 실습하세요.</li>
</ul>
<hr>
<h3 id="2-git을-실전-프로젝트에-활용하기21" tabindex="-1"><strong>2. Git을 실전 프로젝트에 활용하기</strong></h3>
<ul>
<li><strong>브랜치 기반 워크플로우</strong>: 팀 프로젝트에서는 브랜치 전략을 수립하여 독립적인 작업 환경을 만드세요.</li>
<li><strong>자동화된 CI/CD</strong>: GitHub Actions, GitLab CI 등과 연동하여 테스트와 배포를 자동화하세요.</li>
</ul>
