Github Pages 블로그 만들기: Git 레포지토리 생성 및 Next.js 설치

Jekyll을 활용해 Github Pages에 블로그를 만드는 분들을 보면서, 자유도 측면에서 약간의 한계를 느꼈습니다.
그래서 더 높은 유연성과 커스터마이징이 가능한 Next.js로 정적 페이지를 생성하여 블로그를 제작해보기로 했습니다.
이번 기회를 통해 학습도 하고, 동시에 블로그도 만들어보고자 이 포스트를 작성하게 되었습니다.

1. Github Repository 생성

Github 블로그 개설을 위해서 Github 계정이 필요하기 때문에 계정을 생성해주시고 아래 단계를 진행해주세요.
Github Pages를 통해 블로그를 만들기 위해 아래와 같이 Repository명을 설정합니다.

plain
[username].github.io

예를 들어, Github 아이디가 wxexam이라면 Repository 이름은 wxexam.github.io가 됩니다.
아래 이미지를 참고해주세요.

생성이 완료되었다면 다음으로 넘어가도록 하겠습니다.

2. Next.js 프로젝트 생성

다음은, Next.js 프로젝트를 생성합니다. 공식 홈페이지에 최신 버전의 Next.js를 설치할 수 있는 명령어를 제공하고 있습니다.

아래 명령어를 터미널에 입력하세요.

bash
npx create-next-app@latest my-blog --typescript
cd my-blog

아래와 같이 프로젝트를 설정하였습니다.

  • 프로젝트 이름 : wxexam.github.io
  • TypeScript 사용안함
  • ESLint 사용
  • Tailwind CSS 사용
  • src/ 디렉토리 내부에 소스 작성

2.1 Github Pages 배포를 위한 환경 설정

next.config.js 파일을 열어 다음과 같이 output: 'export' 옵션을 추가해줍니다.

javascript
const nextConfig = {
  output: 'export',
};

module.exports = nextConfig;

output: 'export'는 정적 사이트로 내보내기 위해 설정합니다. github page는 정적사이트를 서비스하기 때문에 정적사이트를 생성하여 해당 파일을 github로 push해주어야 합니다.

2. 배포 브랜치 설정 및 기본 프로젝트 배포

Github Repository에 프로젝트를 Push하기 전에 로컬 Git 초기화 및 원격 저장소를 연결합니다.

bash
git init
git remote add origin https://github.com/[username]/[username].github.io.git
git add .
git commit -m "Initial commit"
git push -u origin main

이제 정적 파일을 생성하고 gh-pages 브랜치로 배포합니다.

  1. package.json에 배포 스크립트를 추가하세요.
json
"scripts": {
  "dev": "next dev",
  "build": "next build",
  "deploy": "npm run build && git add out && git commit -m 'Deploy' && git subtree push --prefix out origin gh-pages"
}
  1. 배포하기:
bash
npm run deploy

3. 배포 확인

배포가 완료된 후 Github Repository의 Settings > Pages로 이동하면 배포된 사이트 주소를 확인할 수 있습니다.
주소는 보통 다음과 같습니다.

plain
https://[username].github.io/

브라우저에 접속하여 정상적으로 블로그가 보이는지 확인하세요.

이렇게 하면 Next.js로 Github Pages에 나만의 블로그를 성공적으로 배포할 수 있습니다!
