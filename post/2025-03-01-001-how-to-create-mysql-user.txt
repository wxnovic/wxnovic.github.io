10:T27ee,<h2 id="mysql에서-애플리케이션-사용자-추가하기0" tabindex="-1">MySQL에서 애플리케이션 사용자 추가하기</h2>
<p>웹 애플리케이션을 운영하다 보면 별도의 데이터베이스 사용자를 생성하여 보안과 접근 권한을 관리해야 할 필요가 있습니다. 특히, 운영 환경에서는 루트(root) 계정을 그대로 사용하는 것은 보안상 바람직하지 않습니다. 따라서, 애플리케이션 전용 계정을 만들고 필요한 권한만 부여하는 것이 일반적인 방법입니다.</p>
<p>이번 글에서는 MySQL에서 특정 애플리케이션 전용 사용자를 추가하고, 해당 사용자에게 권한을 부여하는 방법을 설명하겠습니다.</p>
<p>아래 명령어 구성으로는 프로덕션 환경에 구성하기 힘들긴 하지만, 명령어의 의미와 테스트용으로 정리해보았습니다.</p>
<h2 id="1-mysql-사용자-생성1" tabindex="-1">1. MySQL 사용자 생성</h2>
<p>MySQL에서는 <code>CREATE USER</code> 명령어를 사용하여 새로운 사용자를 생성할 수 있습니다. 아래의 SQL 문을 실행하면 <code>app</code>이라는 사용자가 생성됩니다.</p>
<pre><code class="hljs language-sql"><span class="hljs-keyword">CREATE</span> <span class="hljs-keyword">USER</span> <span class="hljs-string">&#x27;app&#x27;</span>@<span class="hljs-string">&#x27;localhost&#x27;</span> IDENTIFIED <span class="hljs-keyword">BY</span> <span class="hljs-string">&#x27;qweQWE12!&#x27;</span>;
<span class="hljs-keyword">CREATE</span> <span class="hljs-keyword">USER</span> <span class="hljs-string">&#x27;app&#x27;</span>@<span class="hljs-string">&#x27;127.0.0.1&#x27;</span> IDENTIFIED <span class="hljs-keyword">BY</span> <span class="hljs-string">&#x27;qweQWE12!&#x27;</span>;
<span class="hljs-keyword">CREATE</span> <span class="hljs-keyword">USER</span> <span class="hljs-string">&#x27;app&#x27;</span>@<span class="hljs-string">&#x27;%&#x27;</span> IDENTIFIED <span class="hljs-keyword">BY</span> <span class="hljs-string">&#x27;qweQWE12!&#x27;</span>;
</code></pre>
<h3 id="사용자-생성-옵션-설명2" tabindex="-1">사용자 생성 옵션 설명</h3>
<ul>
<li><code>'app'@'localhost'</code> : 해당 사용자는 <strong>서버 내부에서만</strong> 접속할 수 있습니다.</li>
<li><code>'app'@'127.0.0.1'</code> : <strong>127.0.0.1로 접속하는 경우</strong>만 허용됩니다.</li>
<li><code>'app'@'%'</code> : <strong>모든 원격 IP에서의 접속을 허용</strong>합니다. 다만, 보안상의 이유로 특정 IP로 제한하는 것이 더 안전합니다.</li>
</ul>
<h2 id="2-데이터베이스-생성3" tabindex="-1">2. 데이터베이스 생성</h2>
<p>사용자가 사용할 데이터베이스를 생성합니다. MySQL에서 <code>CREATE DATABASE</code> 명령어를 사용하면 새 데이터베이스를 만들 수 있습니다.</p>
<pre><code class="hljs language-sql"><span class="hljs-keyword">CREATE</span> DATABASE app <span class="hljs-keyword">CHARACTER SET</span> utf8mb4;
</code></pre>
<ul>
<li><code>app</code>이라는 데이터베이스를 생성합니다.</li>
<li><code>utf8mb4</code>를 설정하여 <strong>이모지를 포함한 다양한 문자 지원</strong>을 가능하게 합니다.</li>
</ul>
<h2 id="3-권한-부여4" tabindex="-1">3. 권한 부여</h2>
<p>생성한 사용자에게 해당 데이터베이스에 대한 접근 권한을 부여해야 합니다. 이를 위해 <code>GRANT</code> 명령어를 사용합니다.</p>
<pre><code class="hljs language-sql"><span class="hljs-keyword">GRANT</span> <span class="hljs-keyword">ALL</span> PRIVILEGES <span class="hljs-keyword">ON</span> app.<span class="hljs-operator">*</span> <span class="hljs-keyword">TO</span> <span class="hljs-string">&#x27;app&#x27;</span>@<span class="hljs-string">&#x27;localhost&#x27;</span>;
<span class="hljs-keyword">GRANT</span> <span class="hljs-keyword">ALL</span> PRIVILEGES <span class="hljs-keyword">ON</span> app.<span class="hljs-operator">*</span> <span class="hljs-keyword">TO</span> <span class="hljs-string">&#x27;app&#x27;</span>@<span class="hljs-string">&#x27;127.0.0.1&#x27;</span>;
<span class="hljs-keyword">GRANT</span> <span class="hljs-keyword">ALL</span> PRIVILEGES <span class="hljs-keyword">ON</span> app.<span class="hljs-operator">*</span> <span class="hljs-keyword">TO</span> <span class="hljs-string">&#x27;app&#x27;</span>@<span class="hljs-string">&#x27;%&#x27;</span>;
</code></pre>
<h3 id="권한-부여-설명5" tabindex="-1">권한 부여 설명</h3>
<ul>
<li><code>ALL PRIVILEGES</code> : 해당 사용자에게 <strong>모든 권한</strong>을 부여합니다.</li>
<li><code>app.*</code> : <code>app</code> 데이터베이스의 모든 테이블에 적용됩니다.</li>
<li><code>'app'@'localhost'</code> : 로컬 접속 사용자에게 권한을 부여합니다.</li>
<li><code>'app'@'127.0.0.1'</code> : 로컬 루프백 사용자에게 권한을 부여합니다.</li>
<li><code>'app'@'%'</code> : 원격 접속을 허용합니다.</li>
</ul>
<h3 id="세부-권한-부여-옵션6" tabindex="-1">세부 권한 부여 옵션</h3>
<p><code>GRANT ALL PRIVILEGES</code> 대신, 특정 권한만 부여할 수도 있습니다.</p>
<pre><code class="hljs language-sql"><span class="hljs-keyword">GRANT</span> <span class="hljs-keyword">SELECT</span>, <span class="hljs-keyword">INSERT</span>, <span class="hljs-keyword">UPDATE</span>, <span class="hljs-keyword">DELETE</span> <span class="hljs-keyword">ON</span> app.<span class="hljs-operator">*</span> <span class="hljs-keyword">TO</span> <span class="hljs-string">&#x27;app&#x27;</span>@<span class="hljs-string">&#x27;localhost&#x27;</span>;
</code></pre>
<p>이 경우 해당 사용자는 <code>app</code> 데이터베이스에서 조회(SELECT), 삽입(INSERT), 수정(UPDATE), 삭제(DELETE) 권한만 가집니다. 이를 통해 필요 이상으로 강한 권한을 부여하지 않도록 조정할 수 있습니다.</p>
<p>다른 중요한 권한으로는 다음과 같은 것들이 있습니다:</p>
<ul>
<li><code>CREATE</code> : 테이블, 뷰 등을 생성할 수 있음</li>
<li><code>DROP</code> : 테이블 삭제 가능</li>
<li><code>INDEX</code> : 인덱스 생성 및 수정 가능</li>
<li><code>ALTER</code> : 테이블 구조 변경 가능</li>
<li><code>EXECUTE</code> : 저장 프로시저 실행 가능</li>
<li><code>LOCK TABLES</code> : 테이블 잠금 가능</li>
<li><code>GRANT OPTION</code> : 다른 사용자에게 권한 부여 가능 (주의 필요!)</li>
</ul>
<h2 id="4-권한-적용7" tabindex="-1">4. 권한 적용</h2>
<p>MySQL에서 사용자 및 권한 변경 사항을 즉시 적용하기 위해 <code>FLUSH PRIVILEGES</code> 명령어를 실행해야 합니다.</p>
<pre><code class="hljs language-sql">FLUSH PRIVILEGES;
</code></pre>
<h2 id="5-보안-고려사항8" tabindex="-1">5. 보안 고려사항</h2>
<ul>
<li><code>'app'@'%'</code> 사용자는 <strong>모든 IP에서 접근 가능</strong>하므로, 원격 접속이 필요 없는 경우 <strong>삭제하거나 특정 IP로 제한</strong>하는 것이 좋습니다.</li>
<li>비밀번호는 강력하게 설정하고, 정기적으로 변경하는 것이 권장됩니다.</li>
<li>방화벽 또는 MySQL 설정(<code>my.cnf</code>)에서 <strong>원격 접속을 제한</strong>하는 것도 중요합니다.</li>
<li>MySQL 8.0 이상에서는 <code>caching_sha2_password</code> 인증 방식을 사용하므로, 애플리케이션이 지원하는지 확인해야 합니다.</li>
</ul>
