마크다운 언어란?

  • 마크다운 언어는 2004년 존그루버에 의해 만들어 짐
  • 쉽게 읽고 쓸 수 있으며 HTML로 변환이 가능
  • 특수문자나 기호 등을 사용하여 매우 간단한 구조의 문법을 사용하여 웹에서 보다 빠르게 컨텐츠를 작성이 가능

제 블로그도...!

제 블로그도 마크다운으로 작성된 파일을 파싱하여 웹페이지에 렌더링해주고 있습니다.
만약 마크다운 언어를 사용하여 작성하지 않는다면 아래와 같이 HTML태그를 하나하나 입력해주어야 하고,
또 페이지를 동적으로 구성하는 것이 불가능하여 하나의 컨텐츠에 하나의 HTML문서가 나와야하는 상황이 발생할지도 모릅니다.

HTML로 작성하였을 때 :

html
<h2>마크다운 언어란?</h2>
<ul>
  <li>마크다운 언어는 2004년 존그루버에 의해 만들어짐</li>
  <li>쉽게 읽고 쓸 수 있으며 HTML로 변환이 가능</li>
  <li>
    특수문자나 기호 등을 사용하여 매우 간단한 구조의 문법을 사용하여 웹에서 보다
    빠르게 컨텐츠를 작성이 가능
  </li>
</ul>

마크다운으로 작성하였을 때 :

markdown
## 마크다운 언어란?

- 마크다운 언어는 2004년 존그루버에 의해 만들어 짐
- 쉽게 읽고 쓸 수 있으며 HTML로 변환이 가능
- 특수문자나 기호 등을 사용하여 매우 간단한 구조의 문법을 사용하여 웹에서 보다 빠르게 컨텐츠를 작성이 가능

내용이 얼마 되지 않는데도 불구하고 차이가 조금 나는걸 확인하실 수 있습니다!
이처럼 마크다운 언어로 컨텐츠를 작성하면 간단하게 작성하고 작성한 내용을 보기 쉽게 관리할 수 있습니다.

마크다운 문법

마크다운 문법은 특수문자나 기호로 이루어져 있습니다.
하나씩 살펴보도록 하겠습니다.

기본 문법

2.1. 제목(Header)

마크다운에서 제목을 표시하고 싶을때는 #를 사용하여 나타냅니다.

마크다운
markdown
# 제목 1 (가장 큰 제목)

## 제목 2

### 제목 3

#### 제목 4

##### 제목 5

###### 제목 6 (가장 작은 제목)
마크업
html
<h1>제목 1 (가장 큰 제목)</h1>
<h2>제목 2</h2>
<h3>제목 3</h3>
<h4>제목 4</h4>
<h5>제목 5</h5>
<h6>제목 6 (가장 작은 제목)</h6>

2.2. 문단(Paragraph)

마크다운에서는 단락을 만들기 위해 줄 바꿈(Enter)만 하면 자동으로 문단이 생성됩니다.

markdown
이것은 첫 번째 문단입니다.

이것은 두 번째 문단입니다.

html
<p>이것은 첫 번째 문단입니다.</p>
<p>이것은 두 번째 문단입니다.</p>

2.3. 줄바꿈(Line Break)

한 줄을 띄우지 않고 줄바꿈을 원할 경우 스페이스 두 개를 사용합니다.

markdown
이것은 한 줄입니다.  
이것은 다음 줄입니다.

html
<p>
  이것은 한 줄입니다.<br />
  이것은 다음 줄입니다.
</p>

텍스트 서식

3.1. 굵게(Bold)

markdown
**이 텍스트는 굵게 표시됩니다.**

html
<p><b>이 텍스트는 굵게 표시됩니다.</b></p>

3.2. 기울임(Italic)

markdown
_이 텍스트는 기울여집니다._

html
<p><i>이 텍스트는 기울여집니다.</i></p>

3.3. 취소선(Strikethrough)

markdown
~~이 텍스트는 취소선이 적용됩니다.~~

html
<p><del>이 텍스트는 취소선이 적용됩니다.</del></p>

3.4. 강조(Highlight)

markdown
==이 텍스트는 강조됩니다.==

html
<p><mark>이 텍스트는 강조됩니다.</mark></p>

3.5. 인용구(Blockquote)

markdown
> 이것은 인용문입니다.

html
<blockquote>
  <p>이것은 인용문입니다.</p>
</blockquote>

4. 목록 만들기

4.1. 순서 없는 목록(Unordered List)

markdown
- 첫 번째 항목
- 두 번째 항목
- 세 번째 항목

html
<ul>
  <li>첫 번째 항목</li>
  <li>두 번째 항목</li>
  <li>세 번째 항목</li>
</ul>

4.2. 순서 있는 목록(Ordered List)

markdown
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목

html
<ol>
  <li>첫 번째 항목</li>
  <li>두 번째 항목</li>
  <li>세 번째 항목</li>
</ol>

4.3. 중첩 목록(Nested List)

markdown
- 첫 번째 항목
  - 하위 항목 1
  - 하위 항목 2

html
<ul>
  <li>
    첫 번째 항목
    <ul>
      <li>하위 항목 1</li>
      <li>하위 항목 2</li>
    </ul>
  </li>
</ul>

5. 코드 블록과 인라인 코드

5.1. 인라인 코드(Inline Code)

markdown
이것은 `인라인 코드` 입니다.

html
<p>이것은 <code>인라인 코드</code> 입니다.</p>

5.2. 코드 블록(Code Block)

@markdown
```python
print("Hello, World!")

@

```html
<pre><code class="language-python">
print("Hello, World!")
</code></pre>

6. 링크와 이미지

6.1. 링크(Link) 삽입

markdown
[Google](https://www.google.com)

html
<a href="https://www.google.com">Google</a>

6.2. 이미지(Image) 삽입

markdown
![Alt 텍스트](이미지 URL)

html
<img src="이미지 URL" alt="Alt 텍스트" />

6.3. 이미지에 링크 추가

markdown
[![Alt 텍스트](이미지 URL)](링크 URL)

html
<a href="링크 URL">
  <img src="이미지 URL" alt="Alt 텍스트" />
</a>

7. 표(Table) 작성

7.1. 기본 표 만들기

markdown
| 헤더1 | 헤더2 | 헤더3 |
| ----- | ----- | ----- |
| 내용1 | 내용2 | 내용3 |
| 내용4 | 내용5 | 내용6 |

html
<table>
  <tr>
    <th>헤더1</th>
    <th>헤더2</th>
    <th>헤더3</th>
  </tr>
  <tr>
    <td>내용1</td>
    <td>내용2</td>
    <td>내용3</td>
  </tr>
  <tr>
    <td>내용4</td>
    <td>내용5</td>
    <td>내용6</td>
  </tr>
</table>

7.2. 표 정렬(Alignment)

markdown
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
| :-------- | :---------: | ----------: |
| 내용1     |    내용2    |       내용3 |

html
<table>
  <tr>
    <th style="text-align:left;">왼쪽 정렬</th>
    <th style="text-align:center;">가운데 정렬</th>
    <th style="text-align:right;">오른쪽 정렬</th>
  </tr>
  <tr>
    <td style="text-align:left;">내용1</td>
    <td style="text-align:center;">내용2</td>
    <td style="text-align:right;">내용3</td>
  </tr>
</table>

8. 체크리스트(Todo List)

markdown
- [x] 완료된 작업
- [ ] 진행 중인 작업

html
<ul>
  <li><input type="checkbox" checked disabled /> 완료된 작업</li>
  <li><input type="checkbox" disabled /> 진행 중인 작업</li>
</ul>

9. 수식 입력 (LaTeX 활용)

9.1. 인라인 수식

markdown
$E = mc^2$

html
<p>\(E = mc^2\)</p>

9.2. 블록 수식

markdown
$$
E = mc^2
$$

html
<p>$$E = mc^2$$</p>

📌 설명: LaTeX 수식은 일반 HTML에서는 직접 표현되지 않으며, 보통 MathJax 같은 라이브러리를 사용해야 합니다.

10. HTML 태그 사용

10.1. HTML과 마크다운 혼용

markdown
<strong>굵은 텍스트</strong>

html
<strong>굵은 텍스트</strong>

10.2. 스타일 지정

markdown
<span style="color:red">이 텍스트는 빨간색입니다.</span>

html
<span style="color:red">이 텍스트는 빨간색입니다.</span>

마크다운 문서 관리 및 변환

마크다운 문서는 PDF, HTML 등으로도 변환이 가능합니다.

다 외울 필요가....?

다 외우실 필요는 없습니다. 링크를 넣고 싶다면 링크 문법을 찾아서 그때그때 사용하다보면 외워집니다!
마크다운 언어가 있다는 것만 알아두시면 좋을 듯 합니다.

마무리 및 결론

이번 문서를 통해 마크다운 문법과 이를 HTML로 변환하는 방식을 상세히 다뤄보았습니다.
마크다운은 간결하면서도 강력한 기능을 제공하는 문법으로, 다양한 플랫폼에서 문서 작성과 웹 콘텐츠 제작에 널리 사용됩니다.

특히,

  • 인용구(Blockquote) 를 통해 글의 가독성을 높이고,
  • 목록(List) 을 활용해 내용을 체계적으로 정리하며,
  • 코드 블록(Code Block) 을 사용하여 프로그래밍 코드나 명령어를 명확히 표시할 수 있습니다.
  • 또한, 링크(Link)와 이미지(Image) 를 추가하여 더욱 풍부한 문서를 만들 수 있고,
  • 표(Table) 작성 및 체크리스트(Todo List) 기능을 활용하면 정리된 정보 전달이 가능합니다.
  • 마지막으로 LaTeX 수식 을 통해 수학식과 과학 공식을 표현하고, HTML 태그를 활용하여 마크다운을 더욱 확장할 수 있습니다.

이 문서를 참고하면, 마크다운 문법을 실무에서 더욱 효과적으로 활용 할 수 있을 것입니다.
특히, 블로그 글 작성, 프로젝트 문서 정리, 깃허브(GitHub) README.md 파일 작성, 기술 문서 작성 등 다양한 용도로 활용할 수 있습니다.

마크다운의 가장 큰 장점은 단순한 문법으로도 풍부한 문서를 쉽게 작성할 수 있다는 점 입니다.
이제 여러분도 마크다운을 익히고, 활용하면서 더욱 효율적인 문서 작업을 경험해보세요!
