# Next.js로 블로그 만들기: 시작하기 ✨

안녕하세요, 개발자 여러분! 😊 오늘은 **Next.js**를 활용해서 블로그를 만드는 방법을 소개하려고 합니다. Next.js는 React 기반의 프레임워크로, SSR(서버사이드 렌더링)과 정적 사이트 생성(SSG)을 쉽게 구현할 수 있어 빠르고 최적화된 웹사이트를 만들기에 제격입니다.

---

## 1️⃣ 프로젝트 초기 설정

먼저, Next.js 프로젝트를 생성해봅시다. 아래 명령어를 터미널에서 실행하세요.

```bash
npx create-next-app@latest my-nextjs-blog
cd my-nextjs-blog
npm run dev
```

✅ **설명**

- `npx create-next-app@latest my-nextjs-blog`: 최신 Next.js 템플릿 생성.
- `cd my-nextjs-blog`: 프로젝트 폴더로 이동.
- `npm run dev`: 로컬 개발 서버 실행(`http://localhost:3000`).

---

## 2️⃣ 페이지 구성하기

Next.js는 파일 기반 라우팅을 사용합니다. 예를 들어, `pages/index.js`는 `http://localhost:3000/`에 매핑되고, `pages/about.js`는 `http://localhost:3000/about`에 매핑됩니다.

**예제: `pages/index.js`**

```jsx
export default function Home() {
  return (
    <div>
      <h1>Welcome to My Blog! 🎉</h1>
      <p>This is a blog built with Next.js.</p>
    </div>
  );
}
```

---

## 3️⃣ 동적 라우팅 추가하기

블로그라면 포스트별로 동적 URL이 필요합니다. Next.js에서는 `[slug].js` 형식으로 파일을 생성하면 동적 라우팅을 지원합니다.

**예제: `pages/post/[slug].js`**

```jsx
import { useRouter } from "next/router";

export default function Post() {
  const router = useRouter();
  const { slug } = router.query;

  return (
    <div>
      <h1>Post: {slug}</h1>
      <p>This is the content of the post "{slug}".</p>
    </div>
  );
}
```

✅ **설명**

- `useRouter`로 URL 매개변수(`slug`)를 가져옵니다.
- `http://localhost:3000/post/my-first-post`에 접속하면 `my-first-post`가 출력됩니다.

---

## 4️⃣ 정적 사이트 생성 (SSG)

SEO 최적화를 위해 Next.js의 `getStaticProps`와 `getStaticPaths`를 활용해 정적 경로를 생성할 수 있습니다.

**예제: `pages/post/[slug].js`**

```jsx
export async function getStaticPaths() {
  const paths = [
    { params: { slug: "my-first-post" } },
    { params: { slug: "nextjs-guide" } },
  ];
  return { paths, fallback: false };
}

export async function getStaticProps({ params }) {
  return {
    props: {
      slug: params.slug,
    },
  };
}

export default function Post({ slug }) {
  return (
    <div>
      <h1>Post: {slug}</h1>
      <p>This is the content of the post "{slug}".</p>
    </div>
  );
}
```

✅ **설명**

- `getStaticPaths`: 정적으로 생성할 경로를 지정합니다.
- `getStaticProps`: 빌드 시 데이터를 가져옵니다.
